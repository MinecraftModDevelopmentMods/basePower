# Upgrading the Advantage workshop to Minecraft 1.12.2

Use a copy of your world first. Install basePower and matching 1.12.2 builds of the expansions already in the world. Remove the old Advantage jars. Install the 1.12.2 versions of Base Metals, MMDLib as required by Base Metals, and MMD OreSpawn 4.1.3 or later in the 4.x line.

| Minecraft 1.10.2 source | Minecraft 1.12.2 destination |
| --- | --- |
| Power Advantage or basePower | basePower `2.4.4.112021` |
| Steam Advantage or baseSteam | baseSteam `2.2.6.112021` |
| Electric Advantage or baseElectric | baseElectric `2.2.6.112021` |

Forge maps the old registry entries instead of replacing placed blocks. Existing base registry names stay the same. The tile datafixers read the old dotted IDs from both mod families and write namespaced IDs on save. This is not a downgrade path. Restore the whole backup, not just `level.dat`, if you need to go back.

The first load preserves changed Forge headers in `basepower-migration-backups`. Legacy configuration is imported only when there is no replacement file. OreSpawn profiles and owned legacy rules carry forward; conflicting settings require review rather than being reset silently. Already generated terrain is not regenerated by this upgrade.

The original OreSpawn configuration is backed up before import. OreSpawn 4's legacy importer keeps the old frequency and height settings, subject to the new engine's limits on deposit size. If you used a custom legacy biome filter, give it a namespaced biome ID (for example, `minecraft:desert`) before upgrading. An ambiguous filter stops the import rather than allowing the deposit in every biome.

Check storage, loaded muskets, battery charge, fluid contents, drill directions and running jobs. Test output and inventories, not just animations. Save and close Minecraft or stop the server completely, then reopen the same copy and check again.

Other mods' content, including optional converters that depend on missing integrations, is not replaced with air by basePower. Resolve missing dependencies before opening the world. Add-ons that look for the old mod IDs may require their own updates.
